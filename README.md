# NiniPixels — Free Image Resizer & Editor

A free, browser-based image editor I developed to make resizing and editing images simple and accessible.

### Features
- Resize images using pixels, inches, or centimeters
- Lock aspect ratios to prevent distortion
- Crop, rotate, and flip images
- Undo and redo edits
- Adjustable DPI settings
- Export images in PNG, JPEG, and WebP formats
- Interactive canvas with rulers and grid lines

### Technologies
HTML • CSS • JavaScript
